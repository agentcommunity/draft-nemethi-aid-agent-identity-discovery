## Command Line Usage

Formatted text and samples can be generated using `make`.

Command Line Tools are required:
`xml2rfc`, `idnits` (for submission checking)

For setup:

```sh
git clone https://github.com/agentcommunity/draft-nemethi-aid-agent-identity-discovery.git
cd draft-nemethi-aid-agent-identity-discovery
git clone https://github.com/martinthomson/i-d-template lib
make
```

## Building

```sh
make                    # Build all outputs
make lint               # Check for nits
make diff               # Show diff from last published version
```

# Agent Identity and Discovery (AID)

This is the working area for the individual Internet-Draft, "Agent Identity and Discovery (AID)"
(`draft-nemethi-dawn-aid`), which updates the specification to the AID v2.0.0 wire format and
renames the document to include a `-dawn-` name segment, per list guidance from the DAWN mailing
list, so it is discoverable alongside other DAWN-related drafts. It replaces
`draft-nemethi-aid-agent-identity-discovery` (v1.2, individual submission, March 2026).

## Command Line Usage

Formatted text and samples can be generated using `make`.

Command Line Tools are required:
`xml2rfc`, `idnits` (for submission checking)

For setup:

```sh
git clone https://github.com/agentcommunity/draft-nemethi-aid-agent-identity-discovery.git
cd draft-nemethi-aid-agent-identity-discovery
git clone https://github.com/martinthomson/i-d-template lib
make
```

## Building

```sh
make                    # Build all outputs
make lint               # Check for nits
make diff               # Show diff from last published version
```
